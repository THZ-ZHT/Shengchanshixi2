对，这次你的需求已经更清楚了。**你真正要的不是“滚动网页”，而是一个以“一张图片”为核心、由鼠标操控图像从左到右连续变形的 AI 视觉演示首页。**

而且首页不是传统 Landing Page，而更像：

> **一个可以被用户“玩”的 AI Composition Showcase。**

这比前面那种 7 格流程图更适合你们的项目。

# 一、先把方向彻底改掉

你现在想要的应该是：

```text
                         首页
                          │
              ┌───────────┴───────────┐
              │                       │
           上传图片                AI Agent
              │                       │
              ↓                    音频跳动
        Waiting / Processing       “正在理解…”
              │                       │
              └───────────┬───────────┘
                          ↓
                  【核心图片舞台】
                          │
                    鼠标左右控制
                          ↓
Original ──→ Matting ──→ Scene ──→ Light ──→ Shadow ──→ Final
```

**用户不是在“看 7 个页面”。**

用户是在：

> **控制一张图片从原始状态逐渐变成最终合成状态。**

---

# 二、色调我建议彻底换掉

上一张的蓝色科技风确实不适合。

我建议采用：

## 主基调：摄影工作室 / 高级创意软件

### UI

* 米白 / 雾白
* 暖灰
* 石墨黑
* 极少量深绿或墨绿

例如：

```text
Background      #F4F3EF
Surface         #FFFFFF
Text            #17191C
Secondary       #777A7E
Accent          #2E6F61
Soft Accent     #DCE9E4
```

**不要大面积青蓝发光。**

真正的颜色来自：

> **图片本身。**

这样当图片从：

> 原始 → 合成 → 暖光 → 最终

发生变化时，整个网页会跟着“活起来”。

## 15%：Matting

用户向右拖。

不是 fade。

而是：

* 背景降低清晰度
* 背景降低饱和度
* 人物边缘逐渐突出
* 人物层缓慢脱离


# 八、35%～50%：Background

> **“我正在把人物放进另一个世界。”**

# 十、70%～82%：Shadow

这种“由鼠标控制物理过程”的感觉会非常高级。

---

# 十一、82%～94%：Harmonization

这时候开始发生一个非常有意思的现象：

### 整张图片一起变化

包括：

* 色彩
* 对比度
* 噪点
* 景深
* 边缘
* 氛围

从：

> “一个人物放进去”

逐渐变成：

> “本来就是这张照片。”

这正好对应你们的“和谐化”阶段。你的开题报告把色彩、噪点、景深匹配以及光照一致性共同作为最终融合的一部分。

# 三十一、技术实现也会非常清晰

这个版本前端反而比之前简单。

```text
Mouse Position
      ↓
progress 0 → 1
      ↓
Composition State
      ↓
┌────────────────────────────┐
│ Foreground                 │
│ Background                 │
│ Mask                       │
│ Lighting                   │
│ Shadow                     │
│ Harmonization              │
└────────────────────────────┘
      ↓
Visual Morph
```

例如：

```ts
progress = mouseX / viewportWidth
```

然后：

```ts
if (progress < .2)
  state = "extract"

else if (progress < .4)
  state = "compose"

else if (progress < .65)
  state = "lighting"

...
```

更进一步，可以把每个阶段做成：

```text
stateProgress = local progress
```

于是：

```text
0.45
```

不是简单：

> “45% 页面”。

而是：

> **Lighting 阶段已经完成 50%。**
